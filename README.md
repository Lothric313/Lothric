# Lothric

Локальный адаптивный сайт: HTML, CSS и JavaScript без зависимостей. Ровно пять основных блоков: видео, каталог, о бренде, отзывы, подвал; отдельно шапка.

## Запуск

В папке проекта выполните `npm start`, затем откройте http://localhost:4173. Для другого порта задайте переменную `PORT`. Сервер поддерживает HTTP Range для перемотки видео. Остановить: Ctrl+C.

`index.html` можно открыть напрямую, но HTTP-сервер рекомендован для одинаковой работы видео и локального хранения во всех браузерах.

## Файлы

- `index.html` — структура и контент.
- `styles.css` — адаптивный дизайн, локальный Cormorant Garamond, состояния и reduced-motion.
- `sections.css` — типографический блок «О нас», список отзывов, сводка оценок и карта.
- `app.js` — данные коллекции, поиск, фильтры, быстрый просмотр, корзина, отзывы и скролл-видео.
- `server.mjs` — локальный сервер без зависимостей.
- `assets/` — видео, логотипы, шрифты, фотографии и сгенерированные концепты украшений.

## Демонстрационные данные

Изделия, цены, материалы, история, имена и отзывы вымышлены и помечены как демонстрационные. Телефон повторяет референс; email использует зарезервированный домен `.example`. Социальные ссылки открывают пояснение до добавления реальных адресов. Перед подвалом размещена отдельная форма связи: имя, email и сообщение. В демонстрации данные не сохраняются и не отправляются. Подвал содержит крупный логотип и навигацию. настоящей регистрации, оплаты и отправки заказов нет.

Корзина сохраняется в localStorage. Ее можно очистить в окне «Конфиденциальность». Для колец размер выбирается перед добавлением.

## Видео

При скролле внутри первой секции позиция видео синхронизируется с прогрессом прокрутки. Вверх — обратная перемотка. Обновления сглажены и ждут окончания предыдущего seek. Положение sticky-кадра занимает 100vh/100svh; длина секции 260svh задает дистанцию скролла. Постер совпадает с началом видео: логотип на каменном фоне. Отдельный слой с руками отсутствует, при возврате к началу позиция видео устанавливается в ноль. На телефонах композиция сохраняется целиком. При reduced-motion видео остается на первом кадре.

## Перед реальным запуском

Утвердите каталог и материалы, замените демонстрационные отзывы и контакты, подключите сервер для заказов и подписки. Текущая версия создается и проверяется локально в папке проекта.

## О нас и отзывы

Блок «О нас» оформлен без фотографии мастерской: крупная типографика, информация о 100 годах работы, описание дома и ссылка на коллекцию Signature. В отзывах справа одновременно показаны пять текстов с полными именами авторов, слева сверху — 1000+ отзывов и средняя оценка 4.9, слева снизу — интерактивная карта Google Maps с выбранной локацией на Красной площади в Москве. Отзывы и локация демонстрационные. На телефонах сводка идет первой, затем отзывы и карта; картинки украшений из блока отзывов убраны.

## Карусель

`carousel.js` управляет прокруткой каталога. Карусель зациклена в обоих направлениях. Перетаскивание мышью, свайп, стрелки клавиатуры и кнопки переключают изделия. Колесико прокручивает страницу; на устройствах с мышью горизонтальная прокрутка колесом также отключена. Информация выводится только под центральным изображением. `refinements.css` содержит компактную шапку по референсу и оформление карусели.

`smooth-scroll.js` сглаживает вертикальную прокрутку колесиком. При смене направления движение сразу разворачивается; нажатия, клавиатура и перетаскивание полосы прокрутки отменяют инерцию. Сенсорная прокрутка, поля ввода и открытые окна используют стандартное поведение браузера. При reduced-motion сглаживание отключено. Перетаскивание товаров мышью также сглажено и завершается плавным центрированием, включая переход между повторениями коллекции.

После отпускания ЛКМ ближайший к видимому центру товар доезжает из фактического положения через анимацию requestAnimationFrame. На устройствах с мышью нативный scroll-snap отключен, чтобы он не вызывал мгновенный скачок перед анимацией. Проверка промежуточных позиций, повторного ввода и зацикливания: `node scripts/carousel-motion.test.cjs`.

## Исходное видео и мобильный экран

Для ПК используется оригинальный `assets/lothric-motion.mp4` (1920×1080, 60 fps) без повторной обработки и сжатия. Постер `assets/video-start-original.png` извлечен из оригинала в PNG без потерь. Экспериментальные 2K/4K версии сохранены в папке, но сайт их не использует.

На телефонах (мобильная верстка до 899 px) видео и постер не загружаются. Первый экран статичный, высотой в один viewport, с предоставленным фото `assets/mobile-hero.jpg` на весь фон. Надпись «Искусство в прикосновении» расположена над руками, кнопка каталога — внизу; в горизонтальной ориентации они находятся в нижнем свободном ряду. В мобильной шапке используется второе фото `assets/mobile-header.jpg`.

Оформление напоминает состаренные картины: теплые оттенки слоновой кости, фактура холста, редкие трещинки и слегка поврежденные края. `antique.css` содержит оформление, `assets/aged-canvas.svg` — легкую векторную фактуру без внешних ресурсов. Декоративные слои не перехватывают нажатия. Оригинальное видео остается без обработки.

На ПК шапка прозрачна на протяжении первого блока, затем получает однотонный фон `#e7dfd0`. Логотип использует предоставленный вырезанный PNG `assets/logo-cutout.png` и занимает четверть ширины содержимого подвала.
