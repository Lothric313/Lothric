# Концептуальные изображения

Созданы встроенным ImageGen; исходные PNG сохранены здесь, оптимизированные WebP используются сайтом. Это концепты, а не фотографии реальных изделий.

- `wordmark.png` — золотистая подвеска с надписью Lothric по предоставленному логотипу, цепочка, светлый известняк, мягкий студийный свет.
- `monogram.png` — пара золотистых серег с монограммой L по предоставленному логотипу, светлый известняк, мягкий студийный свет.
- `ring.png` — золотое скульптурное кольцо с камнем изумрудной огранки цвета шампанского, светлый известняк.
- `pendant.png` — тонкое колье с зеленым камнем, светлый известняк.
- `earrings.png` — дополнительный концепт золотых серег с прозрачными камнями; сохранен как запасной материал.
- `atelier.png` — архивная концептуальная фотография рук ювелира за рабочим столом; в блоке «О нас» больше не используется.

Промпты: product-mockup для украшений, photorealistic-natural для мастерской; премиальная реалистичная предметная фотография, фактурный каменный фон, нейтральная палитра, без водяных знаков. Для фирменных изделий референсы использовались как точные формы металлических знаков.
